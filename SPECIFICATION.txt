Feature Tree Panel — Specification
====================================

Goal: Render a CAD feature tree from the ArtifactGraph returned by exec_kcl_project.
The tree appears as a new "Features" tab alongside Export / Parameters / Results.

Data Source
-----------
- ArtifactGraph is Record<string, ArtifactNode> where each key is an ArtifactId (UUID)
  and ArtifactNode has { type, codeRef, consumed, ...fields }.
- Node types from engine: plane, path, segment, solid2d, sweep, wall, cap,
  sweepEdge, edgeCut, edgeCutEdge, compositeSolid, pattern, sketchBlock,
  startSketchOnFace, startSketchOnPlane, primitiveFace, primitiveEdge,
  planeOfFace, helix, gdtAnnotation, sketchBlockConstraint.

Tree Structure
--------------
Top-level roots: Sweeps (extrude/revolve/loft/blend/sweep), CompositeSolids, Patterns.
These are the "features" a CAD user cares about.

Under each Sweep:
  - Its base Path (with sub_type label)
  - Walls (side faces)
  - Caps (start/end)
  - SweepEdges (opposite/adjacent)
  - EdgeCuts (fillet/chamfer)

Under each CompositeSolid:
  - solid_ids references
  - tool_ids references

Under each Pattern:
  - source reference
  - copy count

Standalone nodes shown at top level if they have no parent sweep:
  - Planes
  - SketchBlocks
  - Helixes
  - GdtAnnotations

Consumed items are dimmed. Each node shows:
  - Icon (by type)
  - Label: type + sub_type (e.g. "Extrusion", "Fillet", "Cap (End)")
  - Short UUID suffix for identification

Click Interaction
-----------------
Clicking a tree node that has a UUID calls viewer.onEntitySelected with a
SelectionInfo resolved from the artifact graph, same as clicking an edge/face
in the 3D view. This shows the UUID popup and source snippet.

UI Placement
------------
- New "Features" pill tab in #data-pills
- New #features-list panel div in #data-panels
- Collapsible tree nodes via <details>/<summary>

Implementation Files
--------------------
1. index.html — add pill button + panel div
2. styles.css — tree node styling
3. main.ts — buildFeatureTree(), renderFeatureTree(), tab wiring
